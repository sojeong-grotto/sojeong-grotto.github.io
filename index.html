int16_t Tilt_ToScreenX(float accel)
{
    float v = ClampFloat(accel, -60.0f, 60.0f);
    if (fabsf(v) < 6.0f) v = 0.0f;      // deadzone
    float n = v / 60.0f;                  // -1 ~ +1
    float eased = n * n * n;              // cubic easing
    float t = (eased + 1.0f) * 0.5f;      // 0 ~ 1
    return (int16_t)(t * (320 - 160) + 0.5f);
}

/* 50ms task : IMU → 좌표 → 상태 → LCD */
ADXL345_Read(&ax, &ay, &az);

Issue 1 · PLC 동작 ↔ HMI 화면 상태 동기화
PROBLEM
설비는 동작하는데 HMI 램프·메시지가 의도한 시점에 바뀌지 않음
CAUSE
PLC 내부 비트와 HMI 표시용 디바이스가 분리 — 표시 타이밍 불일치
SOLUTION
내부 상태를 표시용 디바이스와 연동하고 갱신 로직 수정 → 화면과 설비 상태 일치
HMI 입력터치 버튼 · 설정값
→
PLC 시퀀스조건 체크 · 적재/비움
→
설비 동작Servo · 드릴
→
상태 반영D 레지스터 → HMI 표시
세 프로젝트를 관통하는 관점
메신저 사용자·조직 데이터의 흐름 · STM32 센서값이 화면 상태가 되는 흐름 · PLC HMI 입력이 설비 동작과 상태로 돌아오는 흐름.
시스템 사이의 데이터와 상태를 정확히 연결하는 개발자로 기여하겠습니다.
